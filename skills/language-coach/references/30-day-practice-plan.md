# 30 天口语计划

给想要一个月安排的人。教练在目标语言里布置当天的任务；这份说明本身是给教练看的。解释语言默认是简体中文，所以向学习者交代“今天练什么”时用解释语言说一句，再进入目标语言练习。

这不是考试日程。某一天没练，下次从那天继续，不必从第 1 天重来。

发音不写死在这份计划里。每一周从当前变体文件里选一个对比，整周都用它做跟读时的那一个点评点。换语言或换变体时，换的是变体文件，不是这份计划。

## 每次练习的形状

大约一次会话能做完：

1. 用目标语言随便说几句，热一下。
2. 做当天的主任务。
3. 用更短的句子把主任务再说一遍。
4. 留下三个可以整块再用的口语框架。
5. 用当天的内容做 3 到 5 句跟读或朗读。

## 四周分别练什么

- **第 1 周（第 1–7 天）。** 短话。把一个意思说完，停住，而不是在脑子里先写成文章。
- **第 2 周（第 8–14 天）。** 把一个概念说清楚。顺序是：它是什么，它有哪几部分，它不是什么，举一个例子。
- **第 3 周（第 15–21 天）。** 留在对话里。会追问，会把没说清的地方补上，会比较，会接一句温和的不同意见。
- **第 4 周（第 22–30 天）。** 更接近真实场合的一段话：解释、答问、不同意、没有稿子的两分钟、和工作或学习有关的五分钟。

## 每天的任务

用学习者自己的生活填内容。下面是任务，不是要背的课文。

| 天 | 主任务 |
| --- | --- |
| 1 | 用四句短话介绍自己。 |
| 2 | 讲昨天晚上做了什么，每句只放一个动作。 |
| 3 | 给一个你熟悉的地方指路。 |
| 4 | 描述一顿饭：有什么、味道如何、和谁一起。 |
| 5 | 说说工作或学习，然后用更短的句子再说一遍。 |
| 6 | 讲一件小事，有开头，有结尾。 |
| 7 | 自由聊。仍然用短句。回顾这一周留下的三个框架。 |
| 8 | 从自己的领域里选一个词，用一句话定义它。 |
| 9 | 说明这个概念里的两到三个部分。 |
| 10 | 说它容易被人误会成什么，以及它不是什么。 |
| 11 | 给一个具体的例子，例子里要有人。 |
| 12 | 把同一个概念讲给完全外行听。 |
| 13 | 回答“它为什么重要”。 |
| 14 | 不看笔记，用两分钟再讲一遍。 |
| 15 | 就今天的话题向教练提三个真的想知道的问题。 |
| 16 | 练习补救：说一句，再改口，用“我的意思是……”把意思拉回来。 |
| 17 | 比较两个选择，并说你偏向哪一个。 |
| 18 | 听一句温和的质疑，先接住，再回答。 |
| 19 | 请教练举一个例子，然后对这个例子做出反应。 |
| 20 | 把话题岔开，再绕回来。 |
| 21 | 一轮对话里双方都要问，也都要答。 |
| 22 | 解释一页你在乎的材料，好像对方看不见标题。 |
| 23 | 就刚才的解释回答三个问题。 |
| 24 | 礼貌地表示不同意，并给一个理由。 |
| 25 | 把一个做法分成不超过五个步骤讲出来。 |
| 26 | 不看笔记，做一次两分钟说明。 |
| 27 | 对方说没听懂时，换一种说法，而不是把原句加大音量再念一遍。 |
| 28 | 用五分钟谈你真实的工作或学习。 |
| 29 | 把词汇本里的十个表达用进一个新话题。 |
| 30 | 完整的一次：交谈、六段复习、跟读。最后只定下个月的一个目标。 |

## 教练怎么用

学习者说出第几天，或说“今天按计划来”，就做表里的那一项。他们想自己选题时，用他们的题，保留这一天要练的能力（短句、把概念说清、接话、或一段真实场合的话）。

跟读时的发音点来自变体文件，一周一个。例如美式英语的一周可以只盯闪音，英式英语的一周可以只盯 BATH 或非卷舌。不要在计划之外临时加一组音。
