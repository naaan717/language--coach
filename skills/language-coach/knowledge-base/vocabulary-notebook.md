# 词汇本 / Vocabulary notebook

只收录学习者明确要求保存的条目，例如说过 “Add this to my vocabulary”。意思用解释语言，默认简体中文。词语和例句用目标语言。

每次会话的“词汇更新”整段贴到表格下面，旧行不要删。复习时从这里挑，而不是从记忆里重想。

| 日期 | 变体 | 词语或表达 | 意思 | 自然例句 | 搭配或用法 | 再用过 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

## 怎么记一条

- **变体**填 `en-US` 或 `en-GB`，避免把两种拼写混在同一条里当成同一个词。
- **意思**写一句人话，不写词典定义。
- **自然例句**用口语长度，并且是学习者自己的话题，而不是例句网站上的句子。
- **再用过**记最近一次真正用出来的日期。空着表示还只是见过。
