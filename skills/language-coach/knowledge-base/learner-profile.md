# 学习者档案 / Learner profile

教练开场时读取这份档案。改设置就改这里，不必改技能。

```text
target_variant: en-US
explanation_language: zh-CN
strict_consistency: no
voice_available: unknown
```

- `target_variant`：变体文件名，不含 `.md`。当前随技能提供的是 `en-US` 和 `en-GB`。
- `explanation_language`：纠正、说明和复习所用的语言。默认 `zh-CN`。
- `strict_consistency`：`no` 时，另一种变体的合法说法不当作错误。`yes` 时，教练会把它当成风格上的不统一来提醒。
- `voice_available`：宿主能否播放或接收语音。`unknown` 时由当次会话判断。不能语音就改为朗读。
