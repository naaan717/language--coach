# 常见问题 / Common mistakes

这里记会反复出现的模式，不记每一次口误。一次就过去的说法不要写进来。

教练在复习的“重要纠正”里看到旧模式再次出现时，把次数加一，并更新日期。一种变体里合法、只是和另一种变体不同的形式，不要记成错误。

| 模式 | 变体 | 学习者原话 | 更自然的说法 | 为什么重要 | 出现次数 | 最近日期 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  | 观察中 |

状态用这几个词就够：`观察中`、`正在改`、`已经少见`。

## 值得单独成行的模式

- 听的人会理解错意思。
- 同一个问题已经在两次以上的会话里出现。
- 在当前变体里听着明显不自然，而不是“另一种英语也这么说”。

## 不要写进来的

- 停顿、`um`、说了一半重来。
- 对方已经听懂、而且以后未必再说的长句。
- 美式和英式之间的合法差异。若学习者打开了严格一致，改记在档案的备注里，不记在这张表。
